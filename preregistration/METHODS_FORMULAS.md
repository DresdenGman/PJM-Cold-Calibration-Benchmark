# 方法公式规格 v2.1（公式门修订版，定版）

v2：2026-11-05 冻结版。**v2.1：2026-11-05 经独立公式审查后修订**（本版为实现与论文 Methods 的唯一公式口径）。
背景：PJM 逐小时负荷概率预测；中央区间 (1−α)，α ∈ {0.20, 0.10, 0.05, 0.02}。

## 0. 记号与全局约定
- y_t：小时 t 实际负荷（MW）；小时标签 = 小时起始时刻（EPT，内部计算转 UTC 并处理 DST）；x_t：特征；T_t：足迹平均 2m 气温（°C，ERA5 15 点等权，声明为天气 oracle 输入，见 §8）。
- 分位数网格显式枚举（共 **15** 个）：τ ∈ {0.01, 0.025, 0.05, 0.10, 0.20, 0.30, 0.40, 0.50, 0.60, 0.70, 0.80, 0.90, 0.95, 0.975, 0.99}。例外：L1 的 2014 H-1H 复现臂保留 PHASE2A 原生 7 分位数集 {0.01, 0.05, 0.25, 0.50, 0.75, 0.95, 0.99}（仅复现用途，区间端点由其相邻分位按 CQR 同法构造并注明）。
- **q̂ 定义**：q̂_τ(x) 指基学习器原始输出经逐点排序（pointwise sorting）后的分位数函数；校准、调参、预测、评估全程使用同一个 q̂。残差记 r = y − q̂_τ；区间端点记 L、U。
- HDH_t = max(0, 18.3 − T_t)。
- 热记忆（递归式，冻结）：M 在每时代数据起点初始化 M_{t0} = T_{t0}；M_t = 0.04·T_t + 0.96·M_{t−1}。不跨事件重置；T 缺失小时以最近可用 T 前向填充并计数报告，M 相应延续。
- **次序统计量算子（全规格统一）**：对样本集 S（大小 n）与尾部水平 β：k = ⌈(n+1)(1−β)⌉；Q_β(S) = S_(k)（1 ≤ k ≤ n 时）；k = n+1 或 n = 0 时 Q_β(S) = +∞。禁止插值、禁止以 max 封顶。有限截断所需最小 n：联合 CQR（β=α）为 α=0.20/0.10/0.05/0.02 → 4/9/19/49；单侧（β=α/2）→ 9/19/39/99。
- **数据三分（全时代统一）**：D_fit ≺ D_tune ≺ D_cal ≺ 预测起点。按训练期切分：D_cal_train = 训练期最后 92 天；D_tune = 其前 273 天；D_fit = 其余全部。基学习器只在 D_fit 上拟合；σ0 与 γ 只在 D_tune 上定；最终保形截断只在 D_cal 上算。评估冬季中事件之前的小时仅可追加进 D_cal（事件特定校准），永不进入 D_tune/D_fit。
- **理论声明（全文唯一口径）**：保形覆盖只在“校准分数与测试分数在给定已拟合打分规则下条件可交换”时成立：Pr{Y* ∈ C(X*) | D_fit} ≥ 1−α；Mondrian 版另需箱内可交换。不对任何单个已实现冷事件声称覆盖保证。

## 1. CQR（C1 全局；C2、C4 的基础）
τ_lo = α/2、τ_hi = 1−α/2。校准分数 E_i = max{ q̂_{τ_lo}(x_i) − y_i , y_i − q̂_{τ_hi}(x_i) }（联合分数，β = α）。
截断 Q = Q_α({E_i})（§0 算子）。**只扩张变体（冻结声明）**：Q⁺ = max(0, Q)；C(x) = [ q̂_{τ_lo}(x) − Q⁺ , q̂_{τ_hi}(x) + Q⁺ ]。Q = +∞ 时区间为全实数轴（宽度记 ∞，按 §7 卫生规则处理）。

## 2. C2 温度分层 Mondrian（双轨，冻结修正案 A1）
分箱（按 T，预测时可得）：B1: T ≤ −15；B2: (−15, −10]；B3: (−10, −5]；B4: (−5, 0]；B5: T > 0（°C）。
每箱以 §0 算子在箱内 D_cal 分数上算 Q_k（n_k = 箱内校准数；n_k = 0 或 k 越界时 Q_k = +∞），全局 Q_global 同法。
- **C2a（保证保持版）**：Q_k^use = max{Q_k, Q_global}，再取只扩张 Q⁺。Mondrian 覆盖语言只允许用于 C2a 且附 §0 条件声明。
- **C2b（收缩启发版）**：Q̃_k = (n_k·Q_k + m·Q_global)/(n_k + m)，m = 50；n_k = 0 时 Q̃_k := Q_global；Q_k = +∞ 而 n_k > 0 时 Q̃_k := +∞（不许 0×∞ 运算）。标注为启发式、无 Mondrian 保证。
两轨都跑都报。

## 3. C4 温度超额缩放（非对称，相对参数化）
尺度：σ0 = max{ 1 MW, median_{i∈D_tune} | y_i − q̂_0.5(x_i) | }（只在 D_tune 上拟合）。
s(x) = σ0 · (1 + γ · HDH)，γ 无量纲（每 HDH 单位的相对放大率）。
单侧分数：E^hi_i = ( y_i − q̂_{τ_hi}(x_i) ) / s(x_i)，E^lo_i = ( q̂_{τ_lo}(x_i) − y_i ) / s(x_i)。
**尾部分配**：β_lo = β_hi = α/2；各侧截断 Q^s = Q_{α/2}({E^s_i})（在 D_cal 上算），只扩张 Q^{s+} = max(0, Q^s)。
区间：C(x) = [ q̂_{τ_lo}(x) − Q^{lo+}·s(x) , q̂_{τ_hi}(x) + Q^{hi+}·s(x) ]。
参数选择：(γ_hi, γ_lo) 各自在 D_tune 内层留出（D_tune 后 25%）上独立网格搜索，γ ∈ {0, 0.02, 0.05, 0.1, 0.2, 0.4}，**按 α 逐级调**（每个名义水平一组 γ）；目标 = 留出覆盖最接近名义，同分取平均宽度最小，再同分取 γ 较小者（确定性 tie-break 顺序写死）。选定后冻结 γ，最终截断只在 D_cal 上重算。

## 4. C3 近因自适应（projected ACI，经验基线——无长期保证语言）
- 分数定义按目标水平 α* 固定：E^{α*}_i = max{ q̂_{α*/2}(x_i) − y_i , y_i − q̂_{1−α*/2}(x_i) }；自适应只改截断所用的水平 α_t，不改分数定义。每 (α*, horizon, learner) 一套独立状态，α_1 = α*。
- 时钟窗：状态在发布时点 s 处使用 I(s) = { i : s − 2160h ≤ v_i < s , a_i < s }（v_i 为目标小时、a_i 为标签可得时刻 = 目标小时结束 +1h）；n = |I(s)|，截断用 §0 算子（含空集 → +∞ 规则）。冬季初始化：以 D_cal 分数（在发布掩码下构造的真样本外分数）填充初始窗。
- 更新：err_t = 1{ y_t ∉ C_t }；α_{t+1} = α_t + η(α* − err_t)，η = 0.002；投影截断 [0.001, 0.5]。**标注：projected ACI 经验变体，不援引未投影 ACI 的长期覆盖结论。**
- **延迟反馈（双臂统一）**：按发布批次推进——H-DA 臂以日为批次：整批目标日的截断与 α 状态冻结，批内标签在批结束后才可用于更新；H-1H 臂以小时为批次（标签 1 小时后可得）。事件不触发任何重置；状态跨事件 onset 连续携带。
- Onset 段：O_e = { s_e, …, min(e_e, s_e + 71h) }，单列报告。

## 5. L3 位置-尺度统计模型
y_t = μ(x_t) + σ(x_t)·ε_t。
- μ：基 B = [自然三次样条(T；节点取 D_fit 中 T 的 {5,25,50,75,95}% 分位 + 边界取观测极值；**边界外线性外推，斜率取边界段斜率**) + M_t + HDH + 截距 + 167 个参考编码的小时×星期虚拟（参考 = 周一 00 时）+ 年趋势]。惩罚估计 β̂_λ = argmin { ||y − Bβ||² + λ βᵀPβ }，P 为样条系数二阶差分惩罚（虚拟变量不惩罚）；GCV(λ) = ||y − H_λ y||² / [ n (1 − tr(H_λ)/n)² ]，节点/P/λ 只用 D_fit 定。
- σ（去循环定义，冻结）：r_i = y_i − μ̂(x_i)；z_i = log( max(|r_i|, ε_r) / 1 MW )，ε_r = 1 MW；â = argmin_a Σ (z_i − aᵀh_i)²，h = (1, HDH, (−T−10)_+)；σ̂(x) = (1 MW)·exp(âᵀh(x))。口径：正尺度代理，非标准差。
- ε 分布：ε̂_i = (y_i − μ̂(x_i)) / σ̂(x_i)（D_fit 残差）；按 §2 温度箱分箱取次序统计量 F̂_b^{-1}(τ) = ε̂_{b,(⌈n_b τ⌉)}。合并算法（训练内、确定性）：反复把样本数 <200 的最冷组与其较暖邻组合并；最暖组不足时与较冷邻组合并；直至各组 ≥200 或只剩一组（用全局分布）。
- 分位数：q̂_τ(x) = μ̂(x) + σ̂(x)·F̂_{B(T)}^{-1}(τ)。**明示假设**：残差形状仅经温度箱依赖于 x（近似模型）；其样本内分位数无有限样本预测保证，预测区间一律再经 §1–§4 的独立保形校准构造。

## 6. 冷事件总体抽取规则（冻结细化版）
阈值 θ = 训练集 T 的次序统计量 T_(⌈0.02n⌉)。先取 T_t < θ 的极大连续段（T 缺失断开连续性，不得跨缺失连接）；保留长度 ≥24h 的段；再把间隔小时数 g = (s_2 − e_1)/1h − 1 ≤ 12 的相邻保留段合并。**事件总体 = 合并后全跨度（含间隔小时），指标在全跨度上算**，不交替口径。事件清单在任何模型结果之前由脚本生成存档。

## 7. 指标与卫生（冻结）
- C0 := [ q̂_{α/2}(x) , q̂_{1−α/2}(x) ]（重排后原始区间）。
- 覆盖率、上行超越频率、平均宽度、上行 headroom = mean(u_t − q̂_0.5)：在**固定的共同评估索引集**上算；命名事件以事件宏平均为主口径，小时池化平均为副口径，两者都报。
- Pinball（基学习器）：ρ_τ(r)，r = y − q̂_τ，逐 τ 报。**校准后端点 pinball**：P_{α,t} = ρ_{α/2}(y_t − L_t) + ρ_{1−α/2}(y_t − U_t)；校准器间比较用 P 与 Winkler，有限有序端点下 W_{α,t} = 2·P_{α,t}/α（代码中互验）；联合 CQR 不保证单端点尾部概率达名义，明示。
- 无效/无穷处理：Q = +∞ 产生的无穷宽度按 ∞ 计入分数与 headroom（不得丢弃、不得产生 NaN），并单独报告无穷区间计数；只扩张变体下空集不出现。
- 嵌套：校准端点禁止事后排序；需嵌套时向外放大 L*_α = min_{β≥α} L_β、U*_α = max_{β≥α} U_β，在放大后的区间上评估。
- Bootstrap：联合重采样冻结元组 (y_t, q̂_0.5,t, 各方法 L/U) 并对所有方法使用**同一组** 24h 循环块索引；拼接 ⌈n_e/24⌉ 块截断至 n_e；重采样期间不重拟合、不更新 ACI 状态。口径为描述性重采样范围，非置信区间；n_e = 24 的事件标注退化。
- **校准器选择（修正案 A1）**：Δ_{c,e} = W̄_{0,e} − W̄_{c,e}（事件 e 上 Winkler(90) 宏平均的改善）；评估事件 e 时用留一选择 ĉ_{−e} = argmax_c Σ_{j≠e} Δ_{c,j}，判定量为 Δ_{ĉ_{−e}, e}；另报时序选择变体（选 c 时只用更早事件；2014 无更早事件，其时序变体标注为回顾性）。

## 8. 信息集形式化（冻结）
- x_{t|s} = f( { y_i : a_i < s } , ERA5 天气 oracle 输入 )；拟合、调参、校准各行均在同一发布掩码下构造。滚动负荷特征在可得观测处截断（如 as-of 取值）；某特征在截断后 48h 内无可得观测则该行作废并计数。
- H-DA：s_d = 目标日 d 前一日 10:00 EPT（zoneinfo 处理 DST）；提前量由时间戳计算，不硬编码 15–38h 字样于代码逻辑之外。
- H-1H：s = t（逐小时发布，标签 a_i = i 结束后 1h）。
- 天气定义的事件成员资格为回顾性标注，禁止触发任何在线重置。
