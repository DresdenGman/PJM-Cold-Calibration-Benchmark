## 1. 题目、主问题与目标刊（v2 修订）

**工作题目**：When Cold-Spell Calibration Fails to Transfer: A PJM Benchmark of Probabilistic Load Forecasting Across Four Extreme-Cold Events

**主问题**（v2 由“提出修复法”改为“检验迁移”，四方共识）：从历史冷天观测中学到的校准，能否迁移到下一次极端严寒事件？失败时，源于校准支撑不足、基底模型的支撑外局限（如树模型边界饱和），还是分布漂移本身？回顾性跨事件迁移与严格时序评估的结论差多少？

**副线**（保留 v1 的实证资产）：四个 PJM 严寒事件的覆盖崩塌基准（含官方日前预测峰值误差全景）；冬夏同峰对照；诊断分解（协变量漂移 / 冷箱校准稀疏 / 模型误设）。

**目标刊**：**Applied Energy（唯一主投）**。注记：IEEE TSG 现行 scope 排除输电系统负荷预测，不投；TPWRS 仅当成稿另有实质电力系统贡献时再议。

## 2. 贡献清单（v2，按邻居实文收窄后写死）

- C1：**四事件基准 + 双评估总体**——命名事件（2014 涡旋 / 2015 锚日[仅官方误差] / 2018 Snap / 2022 Elliott）与“固定气象规则定义的全部合格冷事件”双总体，堵峰值选择偏差（forecaster's dilemma）。
- C2：**迁移的诚实证据**——同一套校准方法在（a）严格时序因果评估与（b）回顾性留一事件迁移下的系统对照；两者之差本身即结果（任一符号、系统性且可解释，均可成文）。
- C3：**崩塌的诊断分解**——协变量漂移、冷状态校准稀疏、模型误设（含树边界饱和的判别检验：可外推学习器是否复现崩塌）三路分解，给“为什么崩”以可证伪的答案。
- 不再声称：任何 conformal 变体为方法首创（温度分层、Mondrian、波动率缩放、收缩回退均为已有技术，本文只作对比与应用）；不声称运营优越性/可部署。

## 4. 实验矩阵（v2 重构：双时距 × 三学习器 × 五校准器）

**时距（信息集）**：
- H-DA（主）：日前发布——目标日 d 的每个小时只用 d−1 10:00 EPT 发布时点之前可得的数据构造特征（负荷滞后按时间戳截断，约 15–38h 随目标小时而定）；与 PJM 官方日前预测同口径对照（仍用 ERA5 已观测天气，故结论为“天气 oracle 下的结构误差”，明示）。
- H-1H（副）：1 小时自回归 oracle（即已复现的 2014 规格），定位为上界参照。

**基学习器（三家族，判别“单模型伪影”）**：
- L1 QR-GBT（sklearn HistGBR，复现规格：14 特征、max_iter=300、max_depth=6、seed 42、分位数集 {0.01,…,0.99}）。
- L2 可外推变体：LightGBM linear_tree=True，同特征/分位数（检验线性叶是否原生解决支撑外饱和）。
- L3 统计位置-尺度模型：t2m 三次样条 + HDH + 热记忆（过去 72h 温度指数加权均值）的位置-尺度线性模型，分位数由按温度带估计的残差分布给出。

**校准器（数据决定胜负，不预先钦定；v2.1 细化）**：
- C0 无校准（重排后原始区间）；C1 全局 split conformal；**C2a 温度分层 Mondrian 保证保持版（max{Q_k, Q_global}）/ C2b 温度分层收缩启发版（m=50）双轨**；C3 近因自适应 conformal（projected ACI 经验基线、延迟反馈、按发布时间批次冻结状态；事件起始/首日表现单独报告）；C4 温度超额缩放 conformal（相对缩放 s(x)=σ0(1+γ·HDH)，σ0 与 γ 只在 D_tune 上定、每侧尾部分配 β=α/2）；另 C0x 简单等比扩张基线（前沿对照用）。
- 数据与校准纪律：D_fit/D_tune/D_cal 三分（切分见 METHODS_FORMULAS v2.1 §0）；主评估中每事件的校准只用 D_cal（训练末 92 天 + 评估冬事件前小时）；迁移分析中才允许用其他事件残差，且单独成节、明确标注回顾性。全部公式以 METHODS_FORMULAS v2.1 为准。

**特征与卫生**：特征集同 2014 复现规格（H-DA 臂按发布时间截断规则派生）；EIA 训练集的已登记 NaN/损坏值清洗规则沿 PHASE2B §5；分位数交叉率照实报告，评估用单调重排后分位数并标注。

**公式门**：本节涉及的 conformal 分数、缩放函数与位置-尺度模型的全部数学表述，在实验执行前经独立公式审查，意见与采纳均有书面记录。

## 5. 验证设计与判据（v2 重写）

**主验证**：逐事件严格时序因果评估（命名事件 + 冷事件总体双报告；逐事件报告，不 pool 覆盖率冒充独立重复；事件内不确定性用 24h 块自助法描述）。
**次验证**：回顾性 LOEO 迁移（结构与 γ 等超参的跨事件可迁移性），与主验证分节呈现。

- J1（诊断成立）：L1 在三个建模事件的事件窗 cov90 均较同代聚合低 ≥10pp，**且**崩塌在 L2 或 L3 至少一家上同向复现（否则论点收窄为“树类模型的饱和现象”，按机制解释改写，不硬撑普遍性）。
- J2（修复成立）：校准器按**修正案 A1 的留一事件选择规则**选出（评估事件 e 时只用其余事件的 Winkler(90) 改善排序取 ĉ_{−e}，另报时序选择变体；细则见 METHODS_FORMULAS v2.1 §7），被选校准器在时序评估下使 ≥2/3 事件的事件窗 cov90 回到名义 ±5pp 内；且在**超越频率–headroom 前沿**上优于简单等比扩张基线（同 headroom 下超越更少）；且非事件冬季宽度增幅 ≤35%。placebo（非冷窗）不得出现系统性过覆盖（>名义 +5pp 视为失败信号）。
- J3（迁移结论）：报告每校准器的“回顾性迁移 − 时序评估”覆盖差；无过/不过，其系统性与解释即结果。
- 退路（沿 v1）：J2 不成立 → 论文降级为“诊断 + 基准 + 迁移极限”形态（C1+C2+C3 仍成立），标题摘要相应改写，不编新判据。

**指标全集**：覆盖率（80/90/95/98）、pinball、Winkler(90)、区间宽度与上行 headroom、温度十分位可靠性、峰值小时专项、交叉率、事件起始日/首日单列。
