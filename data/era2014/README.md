# 2014 modelling table

The assembled 2014 modelling table (`pjm_era5_modeling_table_2010_2014.csv`, 43,824 hourly rows, 2010-2014) is not redistributed with this repository. See `DATA_SOURCES.md` at the repository root for its exact column specification and how to rebuild it from the public sources (PJM metered load; ERA5 reanalysis via the Open-Meteo archive). Place the rebuilt file in this directory.
